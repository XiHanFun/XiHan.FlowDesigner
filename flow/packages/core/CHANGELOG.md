## 1.0.0-rc.1

### Major Changes

- a15f650: **新增** 首次发布，以原生 Web Components 交付，不绑定前端框架。

  - `@xihan-flow/core`：流程定义的结构（节点、连线、业务数据与扩展数据）、读入检查、校验与问题码、编辑操作（每一步都能求出逆操作）、连线几何、节点类型登记与扩展合并。纯 TypeScript，不依赖 DOM。`@xihan-flow/core/presets/xihan-workflow` 是 XiHan 工作流引擎的节点预设，节点与引擎的活动类型一一对应，流程定义与引擎定义能互相转换。
  - `@xihan-flow/runtime`：`<xh-flow-viewer>` 按节点类型画出流程，标出运行状态与高亮，缩放、平移、定位节点，导出图片；直角连线路由；与 XiHan.UI 内建语言一一对应的界面语言包（`@xihan-flow/runtime/locale`），查看器与设计器共用。
  - `@xihan-flow/designer`：`<xh-flow-designer>` 可视化设计器，包括物料拖放、连线与改连、对齐吸附、拖动画布、选中工具条、自动布局、属性面板、问题列表、流程结构面板、小地图、撤销重做（每一步带说明，另有历史记录面板）、剪贴板与导出图片。最上一条是菜单栏（文件、编辑、视图、帮助，F10 进入），下面是可以定制的工具栏，最下一条是状态栏；宿主的模板标题可以放在菜单栏正中，保存状态放在状态栏右端。设置对话框分基础（主题与主题色、状态栏、自动保存本机草稿、开发者模式与调试日志）、语言、布局、工具栏、画布，以及帮助、快捷键、关于三页，主题与语言只作用于设计器；另有新手引导与开发者模式下整份定义的 JSON 编辑。面板能换栏、收成标题条与浮出，布局随设置保存。节点类型、属性、编辑方式、校验规则、节点渲染、属性编辑器、命令、面板、物料来源、设置分区、引导步骤与导入导出都能经 `extensions` 登记；宿主与扩展可以按 id 执行命令、把剪贴板内容粘贴到指定位置。
