XiHan 工作流引擎预设 ​

@xihan-flow/core/presets/xihan-workflow 是 XiHan.Framework 工作流引擎的节点预设：引擎的每种活动对应一个节点类型，属性键与引擎读的一致，并能与引擎定义 JSON 互转。用法见 XiHan 工作流引擎预设。

下表与各节点类型的属性取自中文文案的预设（createXihanWorkflow({ texts: xihanWorkflowZhCN })）。类型名就是引擎的活动类型。

预设 ​

createXihanWorkflow() ​

ts
declare function createXihanWorkflow(options?: CreateXihanWorkflowOptions): FlowCoreExtension

按文案生成预设扩展。节点类型与属性的文字写在扩展里，换语言就换一个扩展对象（同一个 id，按卸下再装上处理）；物料分类与属性分组的文字交给设计器的 paletteGroupLabels、propertyGroupLabels。受理人规则的编辑方式是 XIHAN_WORKFLOW_ASSIGNEE_RULES，编辑器由宿主经设计器扩展的 editors.byControl 提供；启动变量的编辑方式是 XIHAN_WORKFLOW_START_VARIABLES，设计器内建它的编辑器，宿主同样可以按种类换掉。

CreateXihanWorkflowOptions ​

createXihanWorkflow 的选项。

属性类型说明
texts?XihanWorkflowTextsOverride文案，各部分按键覆盖英文缺省；整套换语言直接传对应的语言包，如 xihanWorkflowZhCN、xihanWorkflowJaJP。
legacyAssignees?boolean审批节点的属性面板里显示旧的受理人写法（Assignees、AssigneesExpression、CcUserIds），缺省 true。为 false 时不登记这三项属性，已有的值照旧读写、往返不丢，只是属性面板里不再显示；缺受理人的问题说明也只提受理人规则。

与引擎定义互转 ​

toWorkflowDefinition() ​

ts
declare function toWorkflowDefinition(document: FlowDocument): XihanWorkflowDefinition

流程文档换成引擎定义：文档 data 里的字段放在前面，接着 nodes、transitions 与 extraProperties。节点坐标写进 extraProperties.designerLayout；有拐点或外观的连线写进 designerEdges，有扩展数据的写进 designerExtensions。节点总有 name 与 properties（引擎的缺省分别是空串与空字典）。

fromWorkflowDefinition() ​

ts
declare function fromWorkflowDefinition(definition: XihanWorkflowDefinition, options?: FromWorkflowDefinitionOptions): FlowDocument

引擎定义换成流程文档。节点坐标取 extraProperties.designerLayout，有节点没有坐标时按连线自左向右分层排出它的坐标；尺寸按活动类型取。连线没有 id 时按「源->目标#序号」补上。Delay 的 DurationSeconds 为数字时换成字符串，其余字段原样搬，值为 null 的字段去掉。结构不对时抛 TypeError。

属性类型说明

XihanWorkflowNode ​

引擎定义里的节点。

属性类型说明
idstring节点 id，流程定义内唯一。
name?string节点名称，即节点的 label。
activityTypestring活动类型，即节点的 type；引擎内置的见 XIHAN_WORKFLOW_ACTIVITY_TYPES，也可以是应用登记的活动。
properties?JsonObject活动属性，键名由各活动约定。
retryPolicy?{ readonly maxAttempts?: number, readonly firstDelaySeconds?: number, readonly backoffFactor?: number } | null重试策略；为空不重试。
timeoutSeconds?number | null挂起超时的秒数，只对会挂起的节点生效；为空不超时。
continueOnError?boolean失败续行：节点最终失败时不让整个实例故障，以 error 结果继续流转。

XihanWorkflowTransition ​

引擎定义里的连线。

属性类型说明
id?string连线 id，流程定义内唯一。
name?string | null连线名称，即连线的 label。
