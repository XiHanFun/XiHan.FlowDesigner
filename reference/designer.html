设计器 ​

<xh-flow-designer> 编辑流程定义，类在 @xihan-flow/designer 里导出为 XhFlowDesigner，调用 defineFlowDesigner() 注册。用法见设计器。

元素 xh-flow-designer ​

属性 ​

属性attribute类型说明
readonlyreadonlyboolean | undefined只读：可以选择与浏览，不能修改；缺省 false。同名 attribute 三态：不写为缺省，写 "false" 为 false，其余写法（空串、"true" 等）为 true。
autoTourauto-tourboolean | undefined设计器第一次显示出来、画布铺好之后自动开始新手引导，缺省开；藏着时不开始；设置里记过 help.tourDone（走完、跳过或关上过一次）时不再自动开始。写 false 关掉，start-tour 命令、帮助页的「开始引导」与 startTour() 照样能开始。同名 attribute auto-tour，写 "false" 是关。
grid—number | false拖动与新建节点时吸附的网格边长，false 不吸附网格；缺省 16。
defaultLayout—DesignerLayout | undefined面板布局的缺省：设置里还没有 layout.panels 时用它，「恢复默认布局」也回到它；不给按各面板登记的位置，全部显示。用户挪了面板、改了显隐或大小，整份布局写进设置的 layout.panels（DESIGNER_SETTING_KEYS.layout）并派发 settings-change。
paletteGroupOrder—readonly string[] | undefined物料面板里先列出的类别及其顺序，其余类别按登记顺序排在后面。
paletteGroupLabels—Readonly<Record<string, string>> | undefined物料面板的类别标题，缺省直接显示 category。
propertyGroupOrder—readonly string[] | undefined属性面板里先列出的分组及其顺序，其余分组按首次出现的顺序排在后面。
propertyGroupLabels—Readonly<Record<string, string>> | undefined属性面板的分组标题，缺省直接显示分组 id。
commandLayout—DesignerCommandLayout | undefined工具栏与各右键菜单的命令排列：toolbar、menu:node、menu:edge、menu:blank → 若干组命令 id。写了某个位置就只显示列出的命令；没写的位置用内置排列，再把 placement 含它的扩展命令追加成一组。
validateOptions—Omit<FlowValidateOptions, 'extensions'> | undefined校验选项：按问题码覆盖严重程度，扩展规则的问题码也认。
router—FlowEdgeRouter | undefined连线路由器，缺省为直角路由。
settings—DesignerSettings | undefined设置的值：扁平的键值，键是「分区 id.条目 id」，如 general.theme、flow.snap；没写的键取条目的缺省值。赋值即生效；用户在设置对话框里改了以后设计器换成新的一份并派发 settings-change。
settingsPolicy—DesignerSettingsPolicy | undefined宿主对设置条目的管控：键是条目键或分区 id，hidden 不显示，locked 只读、说明换成「由所在系统管理」。
settingsStorageKeysettings-storage-keystring | undefined设置存在根所在窗口 localStorage 的哪个键下：给了，连上文档时若没赋 settings 就从这里读，用户改了设置就写回去，标了 secret 的条目不存；读写失败派发 settings-storage-error。不给就不读写。同名 attribute settings-storage-key。
draftKeydraft-keystring | undefined自动保存草稿的键：区分同一页、同一种设计器里的不同流程（宿主写流程 id）；不给时按页面地址区分。设置里开着自动保存时，未保存的修改停手约一秒存成这台浏览器里的草稿；下次装进同一个键的流程、和草稿不一样时问恢复还是丢弃。同名 attribute draft-key。
translations—Partial<FlowDesignerTranslations> | undefined元素自己的文案，压在全局配置之上。

存取器 ​

属性读写类型说明
schema可读写FlowDocument流程定义。赋值时装载、清空撤销历史，视口按实际大小（100%）摆好（赋回当前这一份不重新装载）；读取时得到当前定义。
extensions可读写readonly FlowDesignerExtension[] | undefined扩展：节点类型、节点渲染、属性编辑器、命令、面板、导入器与导出器都从这里来，内置扩展自动排在最前。赋值时当场合并查重，冲突抛 DesignerExtensionError、什么都不变；各扩展的 setup 在元素连上文档时调用、断开时清理。同一个扩展对象换了引用当作卸下再装上，宿主要保持引用稳定。
canUndo只读boolean有可以撤销的一步。
canRedo只读boolean有可以重做的一步。
canPaste只读boolean剪贴板里有内容，paste() 能贴出东西。
xhConfig只读XhConfig设计器这棵子树的配置：设置里选了语言时是这一语言的 UI、designer-shell 与流程语言包，跟随页面时是空对象。设计器自己、里面的元素与它弹出的浮层都按它取 locale 与文案，页面别处不受影响。
canImport只读boolean装了导入器：粘贴与拖进画布的外部内容、openFile() 选的文件都交给它们。
dirty只读boolean有未保存的修改。

方法 ​

方法说明
execute(operations: readonly FlowOperation[], options?: ExecuteOptions): FlowDocument执行一组操作并记为一步撤销；返回新的定义。
undo(): boolean撤销一步；没有可撤销的返回 false。
redo(): boolean重做一步；没有可重做的返回 false。
markSaved(): void把当前状态记为已保存。
addNode(type: string, at?: FlowPoint): FlowNode新建节点并选中：at 是节点中心的世界坐标，缺省放在视口中央（中央被占时往右下错开）；位置吸附网格。
select(selection: Partial<FlowSelection>): void换成选中这些节点与连线，没写的一类清空。
getSelection(): FlowSelection当前选中的节点与连线。
deleteSelection(): boolean删除选中的节点（连带相连的连线）与连线；只读或没有选中时返回 false。
copy(): FlowClipboard | undefined复制选中的节点与两端都被选中的连线，同时写进系统剪贴板；没有选中节点时返回 undefined。
cut(): FlowClipboard | undefined复制选中内容后删除选中的节点与连线，同时写进系统剪贴板；只读或没有选中节点时返回 undefined。
paste(clipboard?: FlowClipboard, options?: { readonly at?: FlowPoint }): FlowSelection粘贴并选中粘贴出的对象，返回它们；每次比上一次多偏移一格网格（不吸附网格时 24）。缺省用设计器剪贴板里的内容，给了 clipboard 时它成为剪贴板内容；给了 at（世界坐标）时内容整体的中心放到那里、左上角吸附网格，不累加偏移。只读或剪贴板是空的时什么都不做，返回空选择。
runCommand(id: string): boolean执行一条命令（内置的或扩展的）：命令存在、此刻可用才执行，返回是否执行了；给扩展与宿主替用户操作设计器用。
openFile(): void弹出选择文件的对话框，选中的文件交给导入器：按扩展顺序问 accepts，第一个接下的导入；导入的片段放在视口中央，整份流程定义换掉当前定义。没有导入器接下时派发 import-error。只读或没有导入器时什么都不做。
export(format: string, options?: Readonly<Record<string, unknown>>): Promise<Blob | string>导出成文件：交给登记了这种格式的第一个导出器，options 原样交给它；没有导出器认这种格式时返回以 RangeError 拒绝的 Promise。
duplicate(): FlowSelection复制选中内容并立即粘贴，偏移一格网格，不改动剪贴板；只读时什么都不做，返回空选择。
align(mode: AlignMode): void对齐选中的节点；少于两个或只读时什么都不做。
distribute(axis: DistributeAxis): void等距分布选中的节点；少于三个或只读时什么都不做。
autoLayout(options?: FlowAutoLayoutOptions): void按连线方向分层排布全部节点，左上角保持在原处，并清除连线的手动拐点；记为一步，只读时什么都不做。没给的方向与间距取设置里「画布」分区的值。
openSettings(section?: string): void打开设置对话框，给了分区 id 就显示那一页：基础是 general，设计器自己的「画布」是 flow。
startTour(): boolean从头开始新手引导：通用步骤加流程与扩展的步骤，同一页里别的引导开着时先收起它；没有能走的步骤时返回 false。
openJsonEditor(): void打开编辑整份流程定义 JSON 的对话框：写出当前定义，边改边按读入检查与校验报问题；没有错误时「应用」整份换上，记一步撤销。只读时只能看、不能应用。
validate(): FlowIssue[]按当前扩展与校验选项校验定义。
getViewport(): Viewport当前视口。
getViewportCenter(): FlowPoint视口中央的世界坐标；画布还没有尺寸时是原点。
setViewport(viewport: Viewport): void设置视口；此后尺寸变化不再自动摆视口。
zoomToFit(): void缩放并平移到让整张图落在视口中央，小图不放大到 100% 以上；此后尺寸变化时重新适配，直到设置视口或在画布上按下指针。
zoomIn(): void以视口中心放大一档。
zoomOut(): void以视口中心缩小一档。
zoomToActual(): void缩放到 100% 并把整张图居中。
scrollToNode(id: string): void把节点居中显示。
revealNode(id: string): void节点没整个落在视口内时把它居中，已在视口内则不动。
revealEdge(id: string): void连线没整条落在视口内时把它移进来，已在视口内则不动。
clientToWorld(clientX: number, clientY: number): FlowPoint浏览器视口坐标换成画布的世界坐标。

事件 ​

事件都是冒泡的 CustomEvent。

事件detail说明
schema-change{ schema: FlowDocument, operations: readonly FlowOperation[], kind: FlowSchemaChangeKind }流程定义变了：带新定义、这次的操作与种类；拖动等成组的修改在结束时合成一次派发，装载新定义时 operations 为空。
selection-changeFlowSelection选中的节点与连线变了。
dirty-change{ dirty: boolean }有没有未保存的修改变了。
issues-change{ issues: readonly FlowIssue[] }流程定义、扩展或校验选项变了之后重新校验，带全部问题。
connect-reject{ source: FlowEndpoint, target: FlowEndpoint, problems: readonly FlowConnectionProblem[] }拖出或改连的连线违反连接约束，没有连上；带两端与全部问题。
node-dblclick{ id: string }双击了节点。
node-contextmenu{ id: string, x: number, y: number }在节点上打开右键菜单，节点没被选中时先选中它；可以取消，取消后内置菜单与浏览器的右键菜单都不出现。
edge-contextmenu{ id: string, x: number, y: number }在连线上打开右键菜单，连线没被选中时先选中它；可以取消。
blank-contextmenu{ x: number, y: number }在画布空白处打开右键菜单；可以取消。
viewport-change{ viewport: Viewport }视口变了：缩放、平移、适配与 setViewport 都会派发。
import-error{ importer?: string, source: DesignerImportSource, error: unknown }导入没有成功：导入器抛了错，或给出的节点、连线或流程定义不合法、用了没登记的节点类型，importer 是导入器的 id；openFile() 选的文件没有导入器接下时也派发，此时没有 importer。
export{ format: FlowImageFormat, blob: Blob }工具栏的导出命令导出了图片，带格式与文件；可以取消，取消后设计器不自己下载，宿主拿 blob 自己存。没被取消时存成 flow.png 或 flow.svg 下载。
saveRecord<string, never>画布有焦点时按了 Ctrl / ⌘ + S；设计器不自己保存。
settings-change{ key: string, value: JsonValue | undefined, settings: DesignerSettings }在设置对话框里改了一条设置，或在外框上挪了面板（键是 layout.panels，值是整份布局）：设计器已换成新的 settings 并生效（主题、主题色、吸附与自动布局的选项、面板布局）；value 为 undefined 表示删掉这个键、回到缺省值。宿主存起来，下次赋回 settings。
settings-storage-errorVisualEnvironmentStorageError读写 settingsStorageKey 指的本机存储失败（内容不是对象、无痕窗口、配额满）；设置留在内存里。

注册 ​

defineFlowDesigner() ​

ts
declare function defineFlowDesigner(): void

注册 <xh-flow-designer> 与它用到的 UI 元素、设计器零件（零件各自带上它们内部用的 UI 元素）；宿主不必再全量注册。重复调用不报错。

FLOW_TOOLBAR_LAYOUT ​

工具栏的缺省排列；commandLayout 没写 toolbar 时用它，再把 placement 含 toolbar 的扩展命令追加成一组。设置与帮助在菜单栏里，工具栏末组只留面板；有导入器时的变化见 flowToolbarLayout。

组命令
1undo redo
2delete duplicate
3align-left align-center align-right align-top align-middle align-bottom distribute-horizontal distribute-vertical auto-layout
4pan-tool zoom-out zoom-in zoom-to-fit zoom-to-actual
5export-png export-svg
6panels

flowToolbarLayout() ​

ts
declare function flowToolbarLayout(hasImporters: boolean): (readonly string[])[]

工具栏此刻的缺省排列：有导入器时在 FLOW_TOOLBAR_LAYOUT 前面多一组打开文件。

flowMenuLayout() ​

ts
declare function flowMenuLayout(subject: FlowMenuSubject, selectedNodes: number): string[][]

右键菜单的缺省排列：节点菜单在选中两个以上时加对齐，三个以上时加分布；空白处的末尾是编辑 JSON。

FlowMenuSubject ​

ts
type FlowMenuSubject = 'node' | 'edge' | 'blank'

右键菜单落在哪类对象上。

类型 ​

FlowSchemaChangeKind ​

ts
type FlowSchemaChangeKind = 'execute' | 'undo' | 'redo' | 'load'

schema-change 的种类：执行操作、撤销、重做，或宿主装载了新定义。

FLOW_PANELS ​

ts
const FLOW_PANELS = { palette: 'palette', outline: 'outline', properties: 'properties', issues: 'issues', minimap: 'minimap', history: 'history' } as const

设计器登记的面板与画布浮动件的 id：宿主写 defaultLayout、settingsPolicy（layout.panels.<面板 id>）时用它，不手写字符串。各有一条开关命令 panel:<面板 id>。

shortcutCancelstring快捷键页：Esc 一行按流程的做法改写的说明。
shortcutContextMenustring快捷键页：Shift + F10 与菜单键一行的说明。
outlineFlowOutlineTranslations流程结构面板（页面结构零件）的标题、帮助、搜索框与空状态，压在零件文案之上。
historyFlowHistoryTranslations撤销历史里一步的说明。
方法说明
propertiesMultiple(count: number): string选中多个对象时属性面板标题下的一行。
propertyLabel(key: string): string属性描述没有给 label 时的标签，key 是 formatJsonPath 写出的属性路径。
issue(issue: FlowIssue, names: FlowIssueNames): string问题的说明文字。
propertyIssue(property: string, message: string): string落在某个属性上的问题：属性名与问题说明拼在一起。
statusSelected(count: number): string状态栏：选中多个对象时左边写的话。
statusDocument(nodes: number, edges: number): string状态栏：什么都没选中时左边写流程里有多少节点与连线。
statusGeometry(x: number, y: number, width: number, height: number): string状态栏：选中一个节点时写它的位置与尺寸（世界坐标，取整）。
startVariableCell(row: number, column: string): string启动变量表里一格的可访问名：第几个变量（从 1 起）、哪一列。

FlowDesignerLocale ​

一种语言的设计器文案：问题说明与内建属性名写成表，其余与 FlowDesignerTranslations 相同。

继承 Omit<FlowDesignerTranslations, 'issue' | 'propertyLabel'>。

属性类型说明
issuesReadonly<Record<FlowIssueCode, FlowIssueMessage>>每个问题码的说明。
propertyLabelsReadonly<Record<FlowBuiltinPropertyKey, string>>内建属性没有给 label 时的属性名。

FlowIssueMessage ​

ts
type FlowIssueMessage = (text: (key: string) => string, type: (key: string) => string) => string

一条问题说明：text 取参数的文字，type 取参数里那个节点类型的显示名。

FlowBuiltinPropertyKey ​

ts
type FlowBuiltinPropertyKey = 'label' | 'style.dashed'

设计器内建的属性路径，formatJsonPath 的写法。
